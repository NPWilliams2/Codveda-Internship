# Tic-Tac-Toe Mini Game

## Description

A console-based Tic-Tac-Toe game developed in C++ as part of the Codveda C/C++ Development Internship.

The application allows two players to compete in a classic Tic-Tac-Toe game. Players take turns placing their symbols on a 3x3 game board, with the program automatically checking for winning combinations, draws, and invalid moves.

## Features
- Two-player gameplay
- Interactive 3x3 game board
- Turn-based player switching 
- Win detection for rows, columns, and diagonals
- Draw detection
- Input validation
- Prevention of invalid or occupied moves
- Play again functionality
- Modular C++ structure using classes, header files, and source files
