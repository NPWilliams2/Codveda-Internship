# Simple File System Simulation

## Description
A console-based Simple File System Simulation developed in C++ as part of the Codveda C/C++ Development Internship

The application simulates a basic file system, allowing users to create, view, rename, delete, and list text files through a menu-driven interface. File are stored locally using C++ file handling, providing a simple simulation of real-world file management operations.

## Features
- Create new text files
- View file contents
- Rename existing files
- Delete files
- List all available files
- Automatic creation of the storage directory
- Input validation
- Error handling for invalid file operations
- Modular C++ structure using classes, header files and source files

## Technologies Used
- C++
- Visual Studio
- C++17 Filesystem Library

## Concepts Demonstrated
- Object-Oriented Programming
- Structures
- File Input/Output(FileI/O)
- Filesystem operations
- Functions
- Error handling
